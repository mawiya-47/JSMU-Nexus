## ✨ Features

| Feature | Description |
|---|---|
| 🏠 **Home Page** | Dynamic hero section with latest bulletins & registrar directories |
| 🎓 **Admissions** | Complete admissions info & online apply portal |
| 📰 **News & Media** | Real-time press coverage & university news |
| 📚 **Syllabus & Colleges** | Affiliated colleges & curriculum details |
| 🏆 **Milestones** | University achievements & legacy |
| 📊 **Grades Checking** | Student result & grade portal |
| 👨‍⚕️ **Clinicians** | Faculty & clinical staff directory |
| 📞 **Contact** | Public cell & contact information |
| 🔐 **Staff Portal** | Secure faculty login workspace |
| 🤖 **AI Integration** | Powered by Google Gemini AI |

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/mawiya-47/JSMU-Nexus.git

# Go into the project
cd JSMU-Nexus

# Install dependencies
npm install

# Add your Gemini API Key in .env
GEMINI_API_KEY="your_api_key_here"

# Start the dev server
npm run dev
```
